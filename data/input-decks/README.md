# Original simulation input decks

These three files are unchanged copies of the input decks deposited by
Madox C. McGrae-Menge with the dataset accompanying McGrae-Menge et al. (2026),
*Counter-streaming heat-flux closure for electron-only collisionless magnetic
reconnection*.

Source: [Zenodo record 21114117](https://zenodo.org/records/21114117),
DOI [10.5281/zenodo.21114117](https://doi.org/10.5281/zenodo.21114117).
The record declares [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
That original license and attribution apply to these files; they are not
Taylor Kalin's newly written verification code.

`../provenance.json` records each original URL, byte count, published MD5 and
verified SHA-256. The original authors' description identifies these files as
the reference-case PIC, one-electron-fluid and two-electron-fluid inputs.
The present audit inspects their prescriptions but does not run these decks.
